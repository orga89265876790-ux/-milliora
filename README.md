# MilliOra

Многопользовательское веб-приложение для самопознания, наблюдения за изменениями и формирования цифрового портрета личности.

## Первый этап

- создан каркас на Next.js и TypeScript;
- подготовлена адаптивная основа интерфейса;
- добавлены метаданные и базовые стили;
- собрана утверждённая Главная страница;
- работают сохранение показателей, сна, фокусов месяца и дневника;
- до подключения общей базы введённые данные хранятся локально на устройстве.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.
